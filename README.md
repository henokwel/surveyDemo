# Demo for O 

Improve the current survey UI without changing its core structure.

### Improvements

- Allow users to switch language at any point during the survey without losing their progress.

- Add simplified versions of each language, such as **Lätt svenska** and **Easy English**, to make questions easier to understand for non-native speakers and the general public.

- Add optional explanatory text for questions to clarify what they mean and reduce ambiguity.

- Improve accessibility and usability through clearer language, better guidance, and a more inclusive survey experience.
